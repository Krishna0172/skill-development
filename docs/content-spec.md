- `output`: you MUST run each `code` with the Python above (`python -I`, cwd = an empty temp dir) and put the EXACT stdout in `answers[0]` (trailing whitespace on each line and trailing newlines are ignored by the grader). Code must be deterministic (no sets of strings whose order varies, no time/random/ids/hash-dependent output), standard library only, < 25 lines.
- `mcq`: vary `answer_index` across 0-3; 4 options, one clearly correct.
- `debug` / `explain` / `qa`: self-graded — the learner ticks which rubric points they covered; include 2-4 rubric points.
